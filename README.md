# Bluetooth Controlled Car Using Arduino UNO

## Overview

This project is a Bluetooth-controlled robotic car built using Arduino UNO, HC-05 Bluetooth Module, and L298N Motor Driver.

The car can be controlled wirelessly from a smartphone through Bluetooth communication.

## Features

- Forward movement
- Backward movement
- Left turn
- Right turn
- Stop function
- Wireless Bluetooth control

## Components Used

- Arduino UNO
- HC-05 Bluetooth Module
- L298N Motor Driver
- DC Motors
- Li-ion Battery Pack
- Chassis and Wheels

## Project Files

- `bluetooth-car.ino` – Arduino source code
- `BLUETOOTH INTRO-1.pdf` – Project report
- `bluetoothcar.c File Reference.pdf` – Documentation
- `circuit_diagram.jpeg` – Circuit connection diagram
- `car_photo.jpeg` – Final hardware model

## Working

The HC-05 Bluetooth module receives commands from a smartphone application.

The Arduino UNO processes the commands and controls the motors through the L298N motor driver.

Commands:

| Command | Action |
|----------|---------|
| F | Forward |
| B | Backward |
| L | Left |
| R | Right |
| S | Stop |
